## 二、发现的问题（Bugs / Issues）

### Bug #1：新建笔记时，错误地显示出"删除"按钮
- 复现步骤：点 New Note → 尚未保存时，右上角就已出现红色 Delete 按钮
- 预期结果：删除按钮只应出现在"已存在/已保存"的笔记上，新建时应隐藏
- 实际结果：新建状态下 Delete 按钮照常显示
- 点击表现：点它没有任何反应（笔记不会被删）
- 影响：界面误导用户，属于非预期的 UI 行为
- 备注：疑似新建笔记与打开已有笔记复用了同一套按钮显示逻辑
- 复现情况：共复现 3 次，现象稳定（新建笔记时 Delete 按钮均会显示，且点击无反应）
